# Retro Arcade — ретро-игровое пространство

Гибридная ретро-игротека, антикафе и игровое пространство с аркадными автоматами, приставками, турнирами, квестами, настольными играми и лаунжем.

## Рабочая концепция
1. Свободная игра / антикафе — оплата за время.
2. Сценарные программы / квесты — групповые игры с ведущим, сюжетом и заданиями.
3. Открытые события — турниры, мини-миссии, чемпионаты и тематические вечера.

Рабочее название концепции — «Аркадная станция времени» (не утверждено).
